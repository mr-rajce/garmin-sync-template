# Journal

Your context for the data: what the watch cannot know. One file per month, e.g. `2030-10.md`:

```
## 2030-10-23
tags: party, alcohol, outdoors
14:00–16:00 party outside.
```

Longer states (illness, injury, travel, medication) go to `periods.md`. Suggested tags and rules: `CLAUDE.md`, section Journal.
